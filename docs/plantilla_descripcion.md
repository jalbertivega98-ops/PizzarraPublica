# Plantilla de descripción (para todos los reels)

## Formato corto (en uso desde el 10/10/2026, a petición de joel)

```
🤯 [GANCHO]
[EMOJI] [Idea 1, una línea]
[EMOJI] [Idea 2]
[EMOJI] [Idea 3]
[EMOJI] [Idea 4]
💬 [PREGUNTA corta]
➡️ [Serie · Ep. X/N · Próximo: …] · 📚 Fuentes en comentarios

[hashtags]
```

Comentario fijado en una sola línea: `📚 Fuentes: [documentos y fechas]. ¿Ves un error? Dínoslo y lo corregimos.` Los enlaces completos van en `docs/`.

## Formato largo (el del reel 1, ya no se usa)

Estructura fija. Los emojis cambian según el tema, pero cada bloque mantiene su función.

```
🤯 [GANCHO: la pregunta o el dato sorprendente del vídeo]

👀 [CONTEXTO en una frase]
👇 Te lo explico en 60 segundos:

[EMOJI TEMÁTICO] [Paso o idea 1]
[EMOJI TEMÁTICO] [Paso o idea 2]
[EMOJI TEMÁTICO] [Paso o idea 3]
[EMOJI TEMÁTICO] [Paso o idea 4]

⚡ Dato extra: [algo curioso que no cupo en el vídeo]

💬 [PREGUNTA para comentar, sin bandos]

📌 Guárdalo para cuando alguien te pregunte
🔁 Compártelo con quien lo necesite

📚 Fuentes en el comentario fijado

[5-8 hashtags: 3 fijos + 2-5 del tema]
```

**Hashtags fijos:** `#PizarraPública #PolíticaParaPrincipiantes #PolíticaEspañola`

**Emojis temáticos de referencia**

| Tema | Emojis |
|---|---|
| Rey / instituciones | 👑 🏛️ ⚖️ |
| Votar / elecciones | 🗳️ 📊 🔢 |
| Tiempo / plazos | ⏳ 📅 ⏰ |
| Discurso / programa | 🎤 📜 |
| Repetir / bloqueo | 🔁 🚫 🧱 |
| Dinero / impuestos | 💶 🧾 🏦 |
| Vivienda / alquiler | 🏠 🔑 📈 |
| Trabajo | 👷 ⏱️ 💼 |
| Sanidad / educación | 🏥 🎓 |

**Neutralidad:** nada de emojis de burla (🤡 💩 😂) asociados a partidos o políticos, ni corazones o fuegos que parezcan apoyar a un bando.
